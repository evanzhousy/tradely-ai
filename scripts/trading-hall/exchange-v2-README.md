# Documentary exchange reconstruction V2

This editable Blender reconstruction follows the supplied NYSE photograph and the generated documentary reference set. The master reference determines the seven-post layout; five cameras observe the same geometry. Dimensions are estimated from photographs, not a measured survey.

## Deliverables

- `artifacts/trading-hall/exchange-v2/exchange-documentary-v2.blend`: standalone scene with packed textures, saved on the master camera.
- `artifacts/trading-hall/exchange-v2/renders/`: five Cycles PNG renders, 1600 × 842, 64 samples, denoised, rendered on Apple Metal GPU.
- `scene-manifest.json`, `render-final-status.json`, and `standalone-verification.json`: scene inventory, actual render completion, and saved-file verification.

The scene contains seven ring-shaped trading posts, 380 market screen surfaces, 24 tower display faces, oak flooring, cream architectural walls, mullioned windows, gallery railings, and ceiling equipment/cabling. Market data is illustrative and labeled as a model study. The five cameras are master overview, reverse balcony, central aisle, workstation close-up, and side overview.

The scene uses Cycles path tracing with daylight and practical interior lights. Camera sensor width is 70 mm for a large-format composition; this is an approximation of the requested IMAX photographic direction, not calibrated IMAX camera simulation. Furniture repetition, architectural ornament, surface wear, and clutter remain simplified compared with the photographic references. The optional proportional trader figures are retained in `EX2_Background traders - editable`, hidden in viewport and render by default; they are not photorealistic people.

## Authoring

1. Run `python3 scripts/trading-hall/generate_exchange_v2_textures.py`.
2. Load `build_exchange_v2.py` through Blender MCP and execute the named construction phases in order: `setup()`, `architecture()`, `posts(0, 3)`, `posts(3, 7)`, `people()`, `lighting_cameras()`, `refine_reference()`, `finish_reconstruction()`, `finalize_views()`, then `save()`. Construction phases are not idempotent; resume the existing scene instead of repeating them.
3. Run the following from the repository root to normalize the saved scene library into a standalone file and render all five cameras:

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b artifacts/trading-hall/exchange-v2/exchange-documentary-v2.blend --python scripts/trading-hall/render_exchange_v2.py -- final
```

The script targets `Tradely_Exchange_Documentary_v2` only. Existing Blender house and earlier exchange scenes were preserved. No webpage or Three.js asset was replaced as part of this Blender reconstruction.

## Texture provenance

The material study reuses the existing CC0 [Poly Haven natural walnut veneer](https://polyhaven.com/a/natural_walnut_veneer) texture set with independent floor/fascia tint and scale. Quote screens, flag texture, and NYSE tower graphic are generated by `generate_exchange_v2_textures.py`. All required image textures are packed into the standalone Blender file. Generated binary assets and render previews remain in the local ignored trading-hall artifact directory; reproducible scripts are under `scripts/trading-hall`.
