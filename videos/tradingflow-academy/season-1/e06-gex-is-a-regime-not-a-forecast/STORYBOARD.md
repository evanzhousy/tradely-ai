# S1E06 storyboard

1. **01 · Start with scope** — GEX is a model view — Selected date, expiry scope, and prior-close context come first. — visual: `scope`
2. **02 · Positive gamma** — Positive is a regime label — Gamma exposure describes modeled sensitivity around the map—not a guaranteed outcome. — visual: `positive`
3. **03 · Negative gamma** — Negative is not a signal — The sign changes the context you inspect; it does not choose a direction for you. — visual: `negative`
4. **04 · Transition** — Find the transition zone — A zero-crossing is a location in the model, not a magic price target. — visual: `transition`
5. **05 · Walls** — Call Wall and Put Wall frame levels — Keep the wall label, the expiry, and the selected date beside the chart. — visual: `walls`
6. **06 · Level map** — Read the map as context — Pair structure with current flow and price evidence before deciding what matters. — visual: `map`
7. **07 · Invalidation** — Name what would change your read — A regime can persist while the active evidence changes. Record the disconfirming observation. — visual: `invalid`
8. **08 · Practice** — Use GEX to ask better questions — Next: compare DEX direction with DEI magnitude—two lenses, not dealer inventory. — visual: `outro`
