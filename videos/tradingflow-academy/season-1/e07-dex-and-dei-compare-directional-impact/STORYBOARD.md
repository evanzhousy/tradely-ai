# S1E07 storyboard

1. **01 · Two lenses** — Do not collapse direction and magnitude — DEX is signed tape context. DEI normalizes directional impact for comparison. — visual: `split`
2. **02 · DEX** — DEX keeps the sign — Read call-versus-put and buy-versus-sell context without calling it dealer inventory. — visual: `dex`
3. **03 · DEI** — DEI makes scale comparable — Use magnitude to compare symbols or contracts; preserve the source and horizon. — visual: `dei`
4. **04 · Rank symbols** — A rank row is a candidate — Relative attention narrows the universe. It does not finish the analysis. — visual: `rank`
5. **05 · Rank contracts** — Move from symbol to contract — Expiry, strike, moneyness, repetition, and Vol/OI restore specificity. — visual: `chain`
6. **06 · Tape** — Return to the prints — A direction label still needs quote context, size, timing, and neighboring prints. — visual: `tape`
7. **07 · Compare** — Compare like with like — Same session · same lens · same horizon · same freshness line. — visual: `compare`
8. **08 · Practice** — Direction is evidence, not a decision — Next: run the full intraday index workflow from discovery to decision. — visual: `outro`
