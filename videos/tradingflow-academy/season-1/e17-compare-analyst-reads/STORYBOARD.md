# S1E17 storyboard

1. **01 · Pair** — Start with two independent reads — Give Analyst A and Analyst B the same SPX 5900 C packet and keep each note sealed until both are written. — visual: `analyst-cover`
2. **02 · Scope** — Make the shared packet explicit — Same contract, session, lens, horizon, quote context, and freshness rule form the comparison boundary. — visual: `scope`
3. **03 · Reads** — Put the resolutions side by side — A retained claim and a lowered claim can both be faithful to the same observed print. — visual: `analyst-reads`
4. **04 · Divergence** — Find the first field that differs — Trace the disagreement to selection, missingness, scope, or interpretation before debating the conclusion. — visual: `divergence-card`
5. **05 · Layers** — Separate facts from interpretations — Timestamp, contract, side, and size are shared facts; persistence and resolution are interpretive layers. — visual: `facts-interpretation`
6. **06 · Evidence** — Add the check that can narrow the gap — Use the same neighboring-leg, OI, follow-through, and invalidation checks on both reads. — visual: `evidence-bridge`
7. **07 · Log** — Record agreement without erasing nuance — Log what matched, what stayed unresolved, and which rule or field needs clarification. — visual: `agreement-log`
8. **08 · Practice** — Make disagreement useful — Next: S1E18 · calibrate the read without collapsing nuance. — visual: `outro-analyst`
