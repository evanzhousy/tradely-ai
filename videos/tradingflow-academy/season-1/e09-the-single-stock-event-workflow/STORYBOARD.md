# S1E09 storyboard

1. **01 · Event clock** — Start with the event — Earnings date, session, and timezone define the window you are researching. — visual: `clock`
2. **02 · DTE** — DTE changes the comparison — A two-day contract and a sixty-day contract are not interchangeable observations. — visual: `dte`
3. **03 · IV** — Put volatility in context — Compare term structure and moneyness before treating an IV print as unusual. — visual: `iv`
4. **04 · Moneyness** — Map the strike to the underlying — Distance from spot is a coordinate, not a directional conclusion. — visual: `moneyness`
5. **05 · Structure** — Inspect the standing map — Use OI, delta-OI, GEX, and walls as separate context layers. — visual: `structure`
6. **06 · Current flow** — Then return to today's tape — Use Option Trades Historical to preserve the session and sequence. — visual: `tape`
7. **07 · Evidence ledger** — Record what would change your mind — Event research stays useful when the observation, scope, and invalidation are explicit. — visual: `ledger`
8. **08 · Practice** — Build the event note — Season 1 closes the loop: discover, inspect, validate, compare, invalidate, replay, decide. — visual: `outro-season`
