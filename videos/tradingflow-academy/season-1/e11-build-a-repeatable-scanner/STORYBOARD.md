# S1E11 storyboard

1. **01 · Define the universe** — Start with the same universe — A repeatable scan begins with a named symbol set and a selected session. — visual: `rank`
2. **02 · Freeze the filters** — Freeze the filters before the result — Record expiry scope, moneyness, volume, OI, and the freshness line before looking at winners. — visual: `scope`
3. **03 · Discover** — Let the scan narrow attention — Ranking is a candidate list; it is not a signal and it does not finish the read. — visual: `discover`
4. **04 · Inspect** — Open the same evidence drawer — Use the same lens, fields, and source every time so one session can be compared with the next. — visual: `inspect`
5. **05 · Validate** — Apply the contract gates — Expiry, strike, moneyness, repetition, and quote context turn a candidate into a scoped observation. — visual: `validate`
6. **06 · Compare** — Compare like with like — Keep the session, lens, horizon, and freshness line constant before ranking alternatives. — visual: `compare`
7. **07 · Replay** — Save the replay recipe — Same universe, same filters, new timestamp: reproducibility is part of the evidence. — visual: `replay`
8. **08 · Practice** — Make the scanner earn trust — Next: S1E12 · turn candidates into a hypothesis log without skipping the invalidation. — visual: `outro-scanner`
