# S1E18 storyboard

1. **01 · Goal** — Calibrate the method, not the answer — Use the same evidence boundaries and resolution vocabulary while preserving legitimate uncertainty. — visual: `calibration-card`
2. **02 · Anchors** — Agree on the shared facts — Timestamp, contract, side, size, session, source, and freshness are anchors before interpretation begins. — visual: `scope`
3. **03 · Vocabulary** — Define the resolution words — Retained means evidence still fits; lowered means an alternative survived; unresolved means the check is incomplete. — visual: `rubric-card`
4. **04 · Layers** — Keep facts and inferences separate — A shared observation can support different provisional readings when the missing check is named. — visual: `definitions-card`
5. **05 · Compare** — Calibrate the boundary of disagreement — If both analysts use the same facts but different resolution, log the exact step that separates them. — visual: `calibration-compare`
6. **06 · Uncertainty** — Let unresolved stay unresolved — Do not convert an incomplete check into a forced yes or no just to make the dashboard tidy. — visual: `uncertainty-card`
7. **07 · Version** — Version the rubric when it changes — A new definition or check belongs in a new rubric version so old reports remain interpretable. — visual: `rubric-version`
8. **08 · Practice** — Make calibration a shared habit — Next: S1E19 · run a disagreement retrospective without rewriting the original reads. — visual: `outro-calibrate`
