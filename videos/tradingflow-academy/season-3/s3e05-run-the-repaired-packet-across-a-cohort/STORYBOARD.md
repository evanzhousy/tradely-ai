# S3E05 storyboard

1. **01 · Handoff** — Open the repaired version — Carry the S3E04 repair forward as a new recipe version; leave the old cohort unchanged. — visual: `compound-card`
2. **02 · Cohort** — Define the rows in scope — Set the symbol, contract, session range, recipe version, and inclusion rules before reading outcomes. — visual: `cohort-card`
3. **03 · Run** — Apply one fixed recipe — Run the same repaired fields across each future row instead of selecting only the clean examples. — visual: `cohort-table`
4. **04 · Log** — Record every resolution — Retain, lower, unresolved, and missing rows so the cohort describes process behavior honestly. — visual: `outcome-ledger`
5. **05 · Compare** — Describe the cohort, not a score — Compare what changed after the repair without turning a small illustrative sample into probability. — visual: `cohort-compare`
6. **06 · Outlier** — Inspect the row that changed — A changed row is a prompt to check quote context, freshness, contract identity, and recipe version. — visual: `outlier-card`
7. **07 · Measure** — Measure process movement — Track missingness, reproducibility, unresolved states, and repair latency—not directional performance. — visual: `measure-card`
8. **08 · Practice** — Publish the repaired cohort — Next: S3E06 · publish the cohort report with repair lineage before the next blind replay. — visual: `s3e05-outro`
