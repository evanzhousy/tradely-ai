# S3E05 narration outline

Run the Repaired Packet Across a Cohort

## 1. 01 · Handoff

**Open the repaired version**

Carry the S3E04 repair forward as a new recipe version; leave the old cohort unchanged.

## 2. 02 · Cohort

**Define the rows in scope**

Set the symbol, contract, session range, recipe version, and inclusion rules before reading outcomes.

## 3. 03 · Run

**Apply one fixed recipe**

Run the same repaired fields across each future row instead of selecting only the clean examples.

## 4. 04 · Log

**Record every resolution**

Retain, lower, unresolved, and missing rows so the cohort describes process behavior honestly.

## 5. 05 · Compare

**Describe the cohort, not a score**

Compare what changed after the repair without turning a small illustrative sample into probability.

## 6. 06 · Outlier

**Inspect the row that changed**

A changed row is a prompt to check quote context, freshness, contract identity, and recipe version.

## 7. 07 · Measure

**Measure process movement**

Track missingness, reproducibility, unresolved states, and repair latency—not directional performance.

## 8. 08 · Practice

**Publish the repaired cohort**

Next: S3E06 · publish the cohort report with repair lineage before the next blind replay.
