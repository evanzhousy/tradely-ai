# S3E03 storyboard

1. **01 · Handoff** — Open the controlled packet — Use S3E02's frozen identity, fields, sequence, and challenges as the shared starting point. — visual: `s3e03-packet`
2. **02 · Assignment** — Give both analysts the same inputs — No hidden fields, changed expiry, or swapped session should enter one analyst's read. — visual: `s3e03-assignment`
3. **03 · Read A** — Let Analyst A write independently — Record the observation, scope, missingness, and provisional resolution before seeing another note. — visual: `s3e03-read-a`
4. **04 · Read B** — Let Analyst B write independently — A second read can preserve the same facts while naming a different unresolved field. — visual: `s3e03-read-b`
5. **05 · Shared** — Compare shared facts first — Align the contract, source lens, timestamp, and observed sequence before comparing interpretations. — visual: `s3e03-shared`
6. **06 · Divergence** — Locate the first split — Mark the earliest field where evidence or method diverged; do not jump to the final conclusion. — visual: `s3e03-divergence`
7. **07 · Resolution** — Keep disagreement inspectable — Retain both notes, label the unresolved state, and carry one repair question into the next review. — visual: `s3e03-resolution`
8. **08 · Practice** — Open the repair loop — Next: S3E04 · repair the first divergence without rewriting either analyst's historical read. — visual: `s3e03-outro`
