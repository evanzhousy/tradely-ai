# S3E11 storyboard

1. **01 · Handoff** — Open the updated packet — Carry the published review, ownership, and repair question into a new method version without editing the old cohort. — visual: `s3e11-handoff`
2. **02 · Scope** — Define the future rows — Set symbol, contract, session range, recipe version, and inclusion rules before reading any new outcome. — visual: `cohort-card`
3. **03 · Freeze** — Keep the recipe fixed — Run the same updated fields across every eligible row; do not tune the packet after seeing the first result. — visual: `compound-card`
4. **04 · Run** — Process every eligible row — Retain clean, changed, unresolved, and missing rows so the cohort describes the method honestly. — visual: `cohort-table`
5. **05 · Log** — Record each resolution and gap — Write the state, missing fields, freshness, and challenge result for every row in the cohort. — visual: `outcome-ledger`
6. **06 · Compare** — Compare versions without blending — Describe what changed between the old and updated recipe while keeping both cohorts under their original rules. — visual: `cohort-compare`
7. **07 · Measure** — Measure the repair question — Track reproducibility, missingness, unresolved states, and repair latency—not directional performance. — visual: `measure-card`
8. **08 · Practice** — Prepare the update report — Next: S3E12 · publish the update with repair lineage and keep the prior cohort visible. — visual: `s3e11-outro`
