# S3E11 narration outline

Run the Next Cohort with the Updated Packet

## 1. 01 · Handoff

**Open the updated packet**

Carry the published review, ownership, and repair question into a new method version without editing the old cohort.

## 2. 02 · Scope

**Define the future rows**

Set symbol, contract, session range, recipe version, and inclusion rules before reading any new outcome.

## 3. 03 · Freeze

**Keep the recipe fixed**

Run the same updated fields across every eligible row; do not tune the packet after seeing the first result.

## 4. 04 · Run

**Process every eligible row**

Retain clean, changed, unresolved, and missing rows so the cohort describes the method honestly.

## 5. 05 · Log

**Record each resolution and gap**

Write the state, missing fields, freshness, and challenge result for every row in the cohort.

## 6. 06 · Compare

**Compare versions without blending**

Describe what changed between the old and updated recipe while keeping both cohorts under their original rules.

## 7. 07 · Measure

**Measure the repair question**

Track reproducibility, missingness, unresolved states, and repair latency—not directional performance.

## 8. 08 · Practice

**Prepare the update report**

Next: S3E12 · publish the update with repair lineage and keep the prior cohort visible.
