# S3E02 narration outline

Build the Controlled Evidence Packet

## 1. 01 · Question

**Keep the question fixed**

Start with the S3E01 process hypothesis; do not let a new packet quietly change what is being tested.

## 2. 02 · Identity

**Freeze the object under review**

Record symbol, contract, expiry, strike, and session before any interpretation enters the packet.

## 3. 03 · Fields

**Make the evidence fields explicit**

Include source lens, as-of timestamp, quote context, neighboring leg, and the next check required.

## 4. 04 · Order

**Preserve the observed sequence**

A packet keeps print, quote, paired leg, persistence, and follow-through in the order they became available.

## 5. 05 · Challenge

**Attach the disconfirming checks**

Name the fields that could lower the claim before the packet is handed to another analyst.

## 6. 06 · Layers

**Separate facts from the read**

Shared facts and scope travel together; provisional interpretation stays labeled as a separate layer.

## 7. 07 · Replay

**Make the packet rerunnable**

Version the fields and preserve missingness so another session can test the same process claim.

## 8. 08 · Practice

**Hand off the controlled packet**

Next: S3E03 · compare the same packet across analysts without forcing agreement.
