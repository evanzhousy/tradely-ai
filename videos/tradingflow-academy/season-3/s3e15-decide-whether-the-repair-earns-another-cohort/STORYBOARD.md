# S3E15 storyboard

1. **01 · Question** — Set the decision rule — Ask whether the repair made the process more inspectable and rerunnable, not whether it produced a preferred direction. — visual: `s3e15-decision`
2. **02 · Evidence** — Check the packet is complete — Verify identity, scope, freshness, sequence, resolutions, challenges, lineage, and missingness before opening another cohort. — visual: `packet-card`
3. **03 · Movement** — Review process movement — Compare reproducibility, missingness, unresolved states, and repair latency without turning them into a scorecard. — visual: `measure-card`
4. **04 · Gaps** — Keep the unresolved boundary — A fair decision leaves limited rows, stale context, and unresolved checks visible beside the recommendation. — visual: `season-boundary`
5. **05 · Choice** — Keep, narrow, or version — Retain the repair, narrow one field, or version the next change; never blend rule versions into one cohort. — visual: `s3e15-choice`
6. **06 · Ownership** — Assign the next cohort owner — Make the reviewer, packet maintainer, replay operator, and escalation path visible before the next run. — visual: `owner-card`
7. **07 · Boundary** — Freeze the next test — Set future-row scope, recipe version, required fields, and invalidation before any new row can influence the method. — visual: `scope`
8. **08 · Practice** — Open the next cohort — Next: S3E16 · run the next cohort under the retained repair boundary and keep this decision historical. — visual: `s3e15-outro`
