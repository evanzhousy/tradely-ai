# S2E05 storyboard

1. **01 · Question** — Open with the question, not the answer — What changed across the SPX 5900 C replay cohort, and what evidence would change the claim? — visual: `report-cover`
2. **02 · Scope** — Put the recipe beside the result — Universe, expiry, moneyness, side, Vol/OI, lens, and as-of rule define what the report can say. — visual: `scope`
3. **03 · Observation** — Separate the print from the interpretation — Report timestamp, contract, side, and size first; a resolution is not intent. — visual: `report-observation`
4. **04 · Cohort** — Show every row that made the sample — Sessions A, B, and C remain visible so selection and missingness can be inspected. — visual: `report-cohort`
5. **05 · Contradictions** — Put disconfirming evidence in the report — Neighboring legs, changed quotes, stale timestamps, and missing follow-through belong beside the claim. — visual: `report-contradictions`
6. **06 · Resolution** — State what the evidence supports — Retained, lowered, or unresolved is defensible; direction and intent stay unasserted. — visual: `report-resolution`
7. **07 · Reproduce** — Make the next analyst able to rerun it — Record recipe version, selected sessions, source lens, and exact comparison fields. — visual: `report-reproduce`
8. **08 · Practice** — Publish the challenge surface — Next: S2E06 · audit the cohort with a blind replay before trusting the workflow. — visual: `s2e05-outro`
