# S2E03 storyboard

1. **01 · Anchor** — Start with the same question — Carry the hypothesis and its low-resolution claim into the next session without rewriting the starting point. — visual: `hypothesis`
2. **02 · Session A** — Capture the baseline session — Session A · 2026-07-24 · SPX 5900 C · ASK 220 · 09:42:16 ET · illustrative scope. — visual: `session-a-observation`
3. **03 · Session B** — Run the same recipe again — Session B uses the same contract fields, filters, and checks with a new timestamp. — visual: `session-b-observation`
4. **04 · Compare** — Compare like with like — Hold contract, lens, horizon, and freshness constant before interpreting persistence or drift. — visual: `session-compare`
5. **05 · Drift** — Keep the difference visible — A changed size, time, paired leg, or quote context is a new observation—not a reason to delete the row. — visual: `drift-card`
6. **06 · Divergence** — Trace the first divergence — Start at the earliest field where the evidence boundary split: selection, scope, quote context, or interpretation. — visual: `retro-branch`
7. **07 · Resolution** — Update without rewriting history — Retained, lowered, or unresolved describes the current evidence; the original sessions stay intact. — visual: `replay-log`
8. **08 · Practice** — Let the replay change the question carefully — Next: S2E04 · build a replay cohort without blending different recipes. — visual: `s2e03-outro`
