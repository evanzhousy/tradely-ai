# S4E01 narration outline

Start a New Question with the Audited Boundary

## 1. 01 · Handoff

**Carry the audited boundary**

Start with the Season 3 audit: preserve history, inherit fields, and keep the next question separate from prior conclusions.

## 2. 02 · Question

**Name one research question**

Ask a bounded question about one session, one source lens, and one decision—not a promise about direction.

## 3. 03 · Scope

**Declare the source and horizon**

Record symbol universe, session window, freshness, contract scope, and the data lens before opening a candidate.

## 4. 04 · Required

**Lock the required fields**

Identity, sequence, source, freshness, and invalidation are intake requirements, not optional annotations.

## 5. 05 · Owner

**Assign the research owner**

Name the reviewer, packet maintainer, replay operator, and escalation path before the first row enters.

## 6. 06 · Packet

**Open a controlled packet**

Keep observed, inferred, contradicted, and unknown states separate so the next workflow remains challengeable.

## 7. 07 · Boundary

**Freeze the next test**

Future rows can test the question; the audited Season 3 history remains published and unchanged.

## 8. 08 · Practice

**Choose the symbol universe**
