# S4E02 narration outline

Choose the Correct Symbol Universe

## 1. 01 · Universe

**Name the canonical universe**

A ranked row belongs to a declared symbol list—not an accidental search result or a remembered watchlist.

## 2. 02 · Session

**Select the session and freshness**

Set the session, as-of line, and source before comparing one symbol with another.

## 3. 03 · Eligibility

**Set the intake rules**

Write the fields a symbol must carry: identity, coverage, freshness, and the required flow lens.

## 4. 04 · Missingness

**Keep stale rows out of the rank**

A missing or stale field is a visible exclusion—not a value to average into attention.

## 5. 05 · Compare

**Compare like with like**

Use one universe, one session, one denominator, and one freshness line before reading relative attention.

## 6. 06 · Rank

**Treat rank as a candidate list**

Rank narrows where to inspect next; it does not assert direction, intent, or a trade decision.

## 7. 07 · Record

**Log the universe boundary**

Save the symbol set, filters, timestamp, owner, and exclusions so another analyst can rerun the same view.

## 8. 08 · Practice

**Rank symbols without a signal**

Next: S4E03 · inspect relative attention without turning the rank into a directional claim.
