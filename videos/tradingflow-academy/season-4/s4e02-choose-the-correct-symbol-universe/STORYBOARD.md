# S4E02 storyboard

1. **01 · Universe** — Name the canonical universe — A ranked row belongs to a declared symbol list—not an accidental search result or a remembered watchlist. — visual: `s4e02-universe`
2. **02 · Session** — Select the session and freshness — Set the session, as-of line, and source before comparing one symbol with another. — visual: `s4e02-session`
3. **03 · Eligibility** — Set the intake rules — Write the fields a symbol must carry: identity, coverage, freshness, and the required flow lens. — visual: `s4e02-eligibility`
4. **04 · Missingness** — Keep stale rows out of the rank — A missing or stale field is a visible exclusion—not a value to average into attention. — visual: `s4e02-missing`
5. **05 · Compare** — Compare like with like — Use one universe, one session, one denominator, and one freshness line before reading relative attention. — visual: `s4e02-compare`
6. **06 · Rank** — Treat rank as a candidate list — Rank narrows where to inspect next; it does not assert direction, intent, or a trade decision. — visual: `s4e02-rank`
7. **07 · Record** — Log the universe boundary — Save the symbol set, filters, timestamp, owner, and exclusions so another analyst can rerun the same view. — visual: `s4e02-record`
8. **08 · Practice** — Rank symbols without a signal — Next: S4E03 · inspect relative attention without turning the rank into a directional claim. — visual: `s4e02-outro`
