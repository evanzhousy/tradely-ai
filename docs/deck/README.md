# Tradely · EASY Residency Season 5 deck

Navigable HyperFrames pitch deck for Tradely's application to YZi Labs EASY Residency Season 5.

## Present

```bash
cd docs/deck
npm run dev
```

That starts `hyperframes present`. Click Present, or press P, to open the audience tab.

- Google Meet: share the audience tab, not the presenter window.
- Zoom: drag the audience tab into its own window and share that window.

Arrow keys, Space, and swipe move through slides. Some slides have fragment reveals (Problem) or a hotspot into beachhead math.

Do not `hyperframes render` this project into a single MP4. The deck is several top-level scenes; a linear export would truncate.

## Check

```bash
npm run check
```
