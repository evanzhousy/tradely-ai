# TradingFlow — investor deck

Company: **TradingFlow** (`tradingflow.com` / `app.tradingflow.com`).
Audience: YZi Labs EASY Residency Season 5, and any $500k accelerator conversation that uses the same sentence.
Not the company: Tradely (`tradely.ai`) — separate product, GTM footnote only.

## The sentence

TradingFlow is the options research desk a human uses today and an agent queries tomorrow. Rank the session, inspect the tape, read the structure. Default agent access is read-only. We do not place trades. We sell the evidence layer at $69/month.

## Allowed claims

- Live US listed-options workbench: Rank, Option Trades, Cookbooks.
- MCP into Claude Code, Cursor, Codex, OpenClaw. Default keys are read-only. `recipe:write` is opt-in, propose-then-confirm.
- Premium $69 / $59 / $49 per month. Seven-day Premium trial, no card.
- Season 5 fit is the **second half** of “agents that price, route and execute… and the data they depend on.”
- Beachhead: people already paying $50–$200/month for flow tools who still cannot defend a print.

## Forbidden claims

- Onchain, stablecoins, agent wallets, routing, or execution.
- GEX as dealer inventory or a forecast.
- Invented MRR, testimonials, win rates, or “AI / MCP / Discord is generally launched.”
- Tradely as the company, or a merged brand.
- “Better Unusual Whales” as the whole pitch.

## Ask

$500k for **distribution**, not another product surface.

- YZi: $150k for 5% + $350k uncapped SAFE.
- YC: $125k for 7% + $375k uncapped MFN SAFE.
